# Cricket No Ball Detection AI 🏏

An AI-powered system for detecting no-balls in cricket matches using machine learning and blockchain technology.

## 🔗 [Live Demo](https://balaji-sai-t.github.io/cricket_ai/)

## 🎯 Features

- **Real-time No Ball Detection**: Advanced AI model to detect no-balls from video frames
- **Blockchain Integration**: Secure storage of match data using smart contracts
- **Analytics Dashboard**: Visual representation of detection metrics and statistics
- **DevOps Integration**: Automated deployment and monitoring

## 🛠️ Technologies Used

- **Frontend**: React, TypeScript, Vite, TailwindCSS
- **Blockchain**: Solidity, Hardhat, Ethereum
- **ML/AI**: TensorFlow, Python
- **DevOps**: Docker, Kubernetes, Terraform

## 📊 Key Components

1. **ML Model**: Validates bowling actions in real-time
2. **Smart Contracts**: Stores match data securely on the blockchain
3. **Analytics**: Provides insights and statistics
4. **CI/CD Pipeline**: Automated testing and deployment

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Balaji-Sai-T/cricket_ai.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```
